# videoSosis — «Отчим, которого боялся весь дом»

Готовый вертикальный ролик по сценарию и голосовой дорожке, переданным для проекта.

## Готовый результат
- MP4, 1080×1920 (9:16), около 87 секунд.
- Оригинальная озвучка встроена в видео.
- Русские субтитры встроены в изображение.
- 6 визуальных сцен, плавное медленное приближение, начальный титр и финальный кадр.
- Музыка не добавлялась, чтобы не заглушать голос и не использовать трек без выбранной лицензии.

## Пересборка
Нужен FFmpeg в PATH и Python 3. Запустить из корня проекта: `python render.py`.

Исходные медиа находятся в `assets/`: голос, сценарий, раскадровка, субтитры и шесть кадров. Полный архив проекта с медиа и готовым MP4 приложен отдельно.

Формат: MP4 / H.264 + AAC / 1080×1920 / 30 FPS / 9:16.

Примечание: субтитры размечены по фразам и общей длительности исходной дорожки; таймкоды можно поправить в `assets/captions.ass`.
